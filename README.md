# Anonto Academy 🎓🛡️

Mobile-first Android cybersecurity learning app designed to be built from GitHub Actions.

## GitHub mobile workflow
1. Create a GitHub repository named `Anonto-Academy`.
2. Upload the contents of this folder to the repository's `main` branch.
3. Open **Actions → Build Android APK**.
4. Run the workflow (or push to `main`).
5. Open the completed workflow and download **AnontoAcademy-debug-apk** from Artifacts.

## Included foundation
- Anonto Academy branding
- 10 cybersecurity modules and lesson roadmap
- Cartoon-teacher architecture
- Teacher voice reference asset
- XP, progress, streaks and achievements
- Safe CTF / mission structure
- Quiz foundation
- Settings for teacher voice, music, subtitles and offline learning
- GitHub Actions APK build

## Safety
Practical cybersecurity content is designed for fictional/isolated labs and authorized learning environments. Do not use the app to attack systems you do not own or have permission to test.

## Music & media
Only use music/video assets that you own or are licensed to distribute in the app. The supplied teacher voice should only be used with the necessary permission.
